# Python Station Project 3
## Python Countdown Timer

A simple command-line countdown timer written in Python.

## Features

- Accepts time input in `H:M:S` format
- Displays a live countdown in `HH:MM:SS` format
- Updates every second
- Prints a message when the timer finishes

## Requirements

- Python 3.x

## How to Run

1. Save the code as `countdown.py`
2. Open a terminal and navigate to the file location
3. Run the script:

```bash
python countdown.py
```
